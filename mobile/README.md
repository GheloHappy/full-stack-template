# Mobile

Expo 57 and React Native starter using Expo Router, TypeScript, NativeWind,
React Query, Zustand, SecureStore, AsyncStorage, and SQLite.

```bash
npm install
npm start
```

Use `npm run android` or `npm run ios` for native integrations that Expo Go does
not support. API URLs come from `app.config.ts`; replace the placeholder values
before connecting the app to a backend.

The starter deliberately keeps screens small. The folders and integration
packages used by the reference app are ready for new domains. See
[`../EXPO_REACT_NATIVE_STRUCTURE_GUIDE.md`](../EXPO_REACT_NATIVE_STRUCTURE_GUIDE.md)
and [`AGENTS.md`](AGENTS.md).
